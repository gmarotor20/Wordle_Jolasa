# Wordle_Jolasa

Wordle jokoa eginda JavaScript,HTML eta CSSrekin.

## Nola jolastu

1. Ireki 'index.html' nabigatzailean.
2. Aukeratu nahi duzun saiakerak eta hitzaren azalera.
3. Sakatu "Jugar".
4. Idatzi hitzak teklatu bidez edo klikatu hitzak teklatu birtualean.
5. Sakatu ENTER komprobatzeko hilera:
   - 🟩: Hitza ondo kokatuta dago.
   - 🟨: Hitza hori dago, baina ez bere posizioan.
   - ⬜: Hitza ez dago.
     
6.Irabazi edo saiakerak amaitzean duzunean, ikusiko duzu zure 10 azken jolas emaitzak eta botoi bat jolasteko berriro.

## Estruktura

```
index.html
css/
  style.css

  code.js
```
## Hizkiaren API

```
https://words-api-sy2x.onrender.com/api/word?lang=es&length=N&number=1
```

## Erregistroa
 
Erregistroa gordetzen da `localStorage`, hizkiarekin,saikerarekin,data eta irabazi edo galdu egin duzun.
